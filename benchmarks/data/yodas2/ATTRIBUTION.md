# YODAS2 から作った長尺評価データ: 出典とライセンス

このディレクトリの字幕 (`ja/captions/*.srt`) は、**YODAS2** に含まれる字幕を元に、手を加えたものです。

## 出典

| 項目 | 内容 |
|---|---|
| 元のデータ | YODAS2 ([`espnet/yodas2`](https://huggingface.co/datasets/espnet/yodas2)、Hugging Face)。日本語の部分集合 `ja000` (手動字幕) |
| 論文 | Xinjian Li ほか, "YODAS: Youtube-Oriented Dataset for Audio and Speech", IEEE ASRU 2023 |
| ライセンス | [Creative Commons Attribution 3.0 (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/) |
| 元の素材 | YouTube で Creative Commons ライセンスを付けて公開された動画と、その字幕 |

このディレクトリの字幕・一覧・区間の印も、CC BY 3.0 で提供します (このリポジトリのコードのライセンスとは別です)。

## 動画と投稿者の示し方

- 動画は、YODAS2 が付けた **仮の ID** (`manifest.tsv` の `audio_id`) で示します。**これは YouTube の動画の ID ではありません。** YODAS2 の配布元は、ID を書き換えて配っており、元の ID を公開していません。
- そのため、**元の動画の URL、題名、投稿者の名前は、このリポジトリには書いていません** (配布元が公開していないので、分かりません)。このプロジェクトは、仮の ID を元の ID に戻すことも、投稿者を特定することもしません。
- 元の動画にたどるには、`manifest.tsv` の `yodas2_subset` と `yodas2_shard` と `audio_id` で、YODAS2 の中の該当するデータを見てください。
- `manifest.tsv` の `speaker` は、声の特徴から機械でまとめた番号です。投稿者や実在の人物を示すものではありません。

## 手を加えた内容

元の字幕に、次の変更を加えています (CC BY 3.0 が求める「変更した旨の表示」)。区間ごとの変更の前後は `ja/caption_changes.tsv` にあります。

| 変更 | 区間の数 | 内容 |
|---|---:|---|
| 話者の印を消す | 285 | `Y:` のような、発話の頭の印 |
| 括弧の注記を消す | 114 | 読み、訳、`（笑）` など、話していない文字 |
| `[ ]` の印を消す | 90 | `[音楽]`、`[拍手]` など |
| `【 】` の説明を消す | 75 | 画面の説明 |
| ふりがなを消す | 33 | `漢字《かんじ》` の `《かんじ》` |
| 括弧の記号だけを消す | 14 | 括弧の中を読み上げている箇所。中の言葉は残す |
| 文字の実体参照を戻す、`BGM` だけの字幕・伏せ字・`♪` を消す | 23 | |
| 言葉を直す | 35 | 聞いて確かめた結果、発話と違っていた言葉 (字幕「米国」・発話「アメリカ」など)。最終評価用だけ |

このほか、次のことをしています。

- 動画を選んでいます。YODAS2 の `ja000` から、長さが 5〜30 分で、3 つの ASR の出力と字幕がよく合う動画を選び、合成音声の動画と、字幕が発話の要約になっている動画を外しました。
- 時刻は、元の字幕のままです。人は確かめていません。
- 音声は、このリポジトリに含めていません。`scripts/prepare_yodas2_audio.py` が、YODAS2 から取得します。

選び方と直し方の詳しい説明、残っている限界は [`docs/guides/benchmark/yodas2-longform-dataset.md`](../../../docs/guides/benchmark/yodas2-longform-dataset.md) にあります。

## 推奨・支持の否定

YODAS2 の作者、元の動画の投稿者、字幕を書いた人が、このプロジェクトやその評価の結果を推奨・支持しているわけではありません。

## 削除の依頼

元の動画の投稿者、または字幕の権利を持つ方から依頼があれば、該当する字幕と一覧の行を削除します。[issue](https://github.com/Mega-Gorilla/livecap-cli/issues) でお知らせください。動画を示す情報 (字幕の一部など) があれば、該当するものを探します。

## 分かっていないこと

- 手動字幕を書いた人が、動画の投稿者本人とは限りません。
- YODAS の収集は、Creative Commons ライセンスの動画を対象にしていますが、すべての動画のライセンスをこのプロジェクトが確かめたわけではありません。

字幕の文だけを少数 (77 本) 置くこと、音声を置かないこと、削除の依頼に応じることで、影響を小さくしています。
